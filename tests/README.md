# Test data

Applicants, contact addresses, credentials and resumes created by tests are fictional. Reserved example domains are used for applicant contact details. No private CV, reference manifest, authenticated profile or applicant database is included.

The `fiveca9d` fixtures retain a structural public-form compatibility schema. Unused posting prose and metadata have been removed. Field identifiers and minimal consent/validation labels are needed to test that changed consent wording is rejected; they are not an endorsement or a permission to submit to a live employer.

Private-CV, external-portal and Windows-vault integrations are opt-in. Do not enable them when running a public/local validation. Temporary browser tests create isolated profiles and fictional files; they do not control a personal Brave profile.
